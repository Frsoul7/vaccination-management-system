# UC001 - Authentication

## 1. Engineering Requirements

### Brief Format

The user launch the application. The system requests for an authentication. 
The user should insert login parameters and a password. The system validates the data inserted and 
authenticates the user in a specific role.

### Complete format

#### Main Actors
User

#### Stakeholders and Interests
* **Administrator:** authenticates in order to configure and manage core information required by the application.
* **Colaborador:** authenticates in order to have access to data which allows the monitoring of vaccination processes.
* **Nurse:** authenticates in order to have access to SNS user health history, to validate data through vaccine administration, and to issue vaccination certificates when requested by SNS users.
* **Receptionist:** authenticates in order to have access to SNS user schedule data for validation.
* **SNS User:** authenticates in order to schedule a vaccine administration.
* **DGS:** wants to guarantee the security and functionality of the application.

#### Preconditions
* users must be registered in the application with a unique username and eligible password.
* have access to the application.

#### Success Guarantee (or Postconditions)
After authentication, each user will have specific options according to its role in the system.

### Main Success Scenario (or Basic Flow)
1. The user launch the application.
2. The system requests for an authentication.
3. User inserts login parameters and a password.
4. The system validates the data and authenticate the user in a specific role.

#### Extensions (or Alternative Flows)
*a. The User cancels the authentication process.
>The user case ends.

3a. The user inserts invalid data.
>1. The system informs which data is wrong.
>2. The system requests a new data input.  
>3. The user insert new valid data.(step 4)  
  >3.1 The user inserts 3 times in a row invalid data.
> 3.2 The user case ends.
    
#### Special Requirements
* Password holding seven alphanumeric characters,
including three capital letters and two digits.
* Only the nurses are allowed to access all user’s health
data.
