# UC003 - Register Vaccine

## 1. Engineering Requirements

### Brief format

The administrator starts the registration of a new vaccine. The system requests
the required data (e.g. designation) to specify a new vaccine type.
The administrator inserts the required information according to the data fields.
The system then checks and presents the data to the administrator and asks him to confirm it.
Upon the administrator confirmation, the system asks the administrator to insert the
specifications (e.g. name and lot number) of the new vaccine. The system validates and
presents the data to the administrator and asks him to confirm it.
Upon the administrator confirmation, the system records the data
and informs about the success of the operation.

### Complete format

#### Main Actor
Administrator

#### Stakeholders and Interests
* **Administrator:** wants to register new vaccines and vaccine types in the system.
* **SNS user:** wants to be administered with a vaccine registered in the system.
* **Nurse:** wants to administer a vaccine which is registered in the system to a SNS user.
* **Center coordinator:** wants to manage the process of vaccination related to the vaccines registered in the system.
* **DGS:** wants new vaccine type and vaccines to be registered in the system, for the vaccination of the population.

#### Preconditions
Existence of new vaccine or vaccine type to be registered in the system.

#### Success Guarantee (or Postconditions)
* Add a new type of vaccine.
* Add a new vaccine.
