# UC005 - Vaccination Certificate Issuance

## 1. Engineering Requirements

### Brief Format
SNS users request a vaccination certificate as confirmation of taking a vaccine. The system validates the SNS users' request.
Then, the certificate is issued by DGS for the SNS user. 


### Complete format

#### Main Actor
SNS User

#### Stakeholders and Interests
* **SNS User:** intends to have the vaccine certificate.
* **Nurse:** upon SNS user request, health center nurses can deliver vaccine certificate on site. 
* **DGS:** the vaccine certificate in necessary in order to comply with society regulations.

#### Preconditions
* Be identified and authenticated;
* Vaccine had been administered.

#### Success Guarantee (or Postconditions)
A SNS user obtains a vaccine certificate with his/her personal data;

### Main Success Scenario (or Basic Flow)
1. SNS users request a vaccination certificate as confirmation of taking a vaccine.
2. The system validates the SNS users' request.
3. The certificate is issued by DGS for the SNS user.

#### Extensions (or Alternative Flows)
*a. The SNS user cancels the vaccine certificate request.
>The user case ends.

1a. The SNS user asks assistance to the nurse of health center to obtain vaccine certificate.
>1. The nurse ask the necessary data of SNS user to verify if the vaccine certificate has been issued by DGS.  
>2. The system validates the nurse's request. 
>3. The certificate is issued by DGS for the SNS user.  
> 3.a Nurse delivers it to SNS user on site.
