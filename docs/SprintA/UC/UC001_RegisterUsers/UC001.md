# UC001 - Register Users

## 1. Engineering Requirements 

### Brief format

The administrator starts the registration of a new user. The system requests
the required data and the role of the user. The administrator inserts
the required information according to the data fields.
The system checks and presents the data to the administrator and asks him to confirm it. 
Upon the administrator confirmation, the system records the data 
and informs about the success of the operation.
