# UC008 - Record Adverse Reactions 

## 1. Engineering Requirements

### Brief Format
During recovery time, a SNS user have an adverse reaction to vaccine.
The nurse identifies and records the event in the system. 

### Complete format

#### Main Actor
Nurse

#### Stakeholders and Interests
* **Nurse:** during recovery time of SNS User, wants to register adverse reactions in case of occurrence.
* **SNS Users:** in case of occurrence, SNS user wants event registered on system. If not, SNS user completes recovery time and can go home. 
* **Center coordinator:** want to include the occurrence of adverse reactions in the reports.
* **DGS:** Track, analyse and report such events.

#### Preconditions
SNS user is in recovery room.

#### Success Guarantee (or Postconditions)
SNS user feels adverse reactions and nurse registers description on system.

### Main Success Scenario (or Basic Flow)
1. SNS user in recovery room has an adverse reaction to vaccine.
2. The nurse identifies the occurrence.
3. The nurse records the event in the system
4. The system returns the success of the operation.

#### Extensions (or Alternative Flows)
*a. The nurse cancels the adverse reaction reporting.
>The user case ends.

1a The SNS user does not have an adverse reaction.
> 1.The system notifies the SNS user by SMS or Email that the recovery period has ended.
