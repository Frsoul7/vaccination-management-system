# UC004 - Vaccine Scheduling

## 1. Engineering Requirements

### Brief Format
A SNS user starts the process to schedule a vaccine. The system requests the following data:  
1. SNS user number;  
2. date and time;  
3. place for vaccination;    
4. type of vaccine;  
5. check if wants schedule confirmation/information by SMS.  
The SNS user inserts the data requested by the system. The system validates the data inserted and verifies the center capacity for that day and time.
The system records the data, and informs the SNS user that should be at selected vaccination center at scheduled day and time.

### Complete format

#### Main Actor
SNS User 

#### Stakeholders and Interests
* **SNS User:** wants to schedule the vaccine.  
* **Receptionist (of health centers):** can help SNS user in scheduling a vaccine administration.  
* **Nurse:** checks the scheduled vaccines.   
* **Center Coordinator:** monitor the vaccination process.  
* **DGS:** promote the mass vaccination and adherence of population (SNS users).  

#### Preconditions
Be identified and authenticated. 


#### Success Guarantee (or Postconditions)
* A SNS user schedules successfully a vaccination event;
* SNS user must respect certain conditions (e.g. number of doses already taken and time interval between doses).

### Main Success Scenario (or Basic Flow)
1. A SNS user starts the process to schedule a vaccine.
2. The system requests data (SNS user number; date and time; place for vaccination; type of vaccine; check if wants schedule confirmation/information by SMS.).
3. The SNS user inserts the data requested by the system.
4. The system validates the data inserted and verifies the center capacity for that day and time.
5. The system records the data.
6. The system informs the SNS user that should be at selected vaccination center at scheduled day and time.

#### Extensions (or Alternative Flows)
*a. The SNS user cancels the scheduling process.
>The user case ends.

1a. The SNS user asks assistance to the receptionist of health center to schedule a vaccine.
>1. The receptionist starts the process to schedule a vaccine.
>2. The system requests data.
>3. The receptionist fulfills the requested data on behalf of SNS user.(step 4)

3a. The SNS user fill all the data fields except the field of type of vaccine.
>1. The application fulfills automatically the field of type of vaccine in accordance with the ongoing outbreak.(step 4)

3b. The SNS user checks in the option of receiving schedule information/confirmation by SMS 
>1. The SNS user fulfills the data field of mobile contact.(step 4)

4a. The system detects that SNS user did not complied with valid data inserted.
>1. The system informs the SNS user about the invalid data inserted.  
> 1a. The user case ends.

6a. The SNS user checked the SMS option
>1. DGS will send an SMS with schedule information/confirmation.
