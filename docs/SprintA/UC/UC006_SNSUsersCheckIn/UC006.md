# UC006 - SNS Users Check-in

## 1. Engineering Requirements

### Brief Format

Receptionist registers on the system the SNS user arrival, at the vaccination
center to take the respective vaccine. The receptionist asks the SNS user for his/her 
"SNS user number" and inserts it on system. The system returns the date and time that SNS user has 
the vaccine scheduled. The receptionist compares the information and acknowledges in
the system that the SNS user is ready to take the vaccine. The system add the SNS user to the queue list.
Finally, the receptionist sends the SNS user to the waiting room.

### Complete format

#### Main Actor
Receptionist

#### Stakeholders and Interests
* **Receptionists:** needs to confirm in the application if a certain SNS User has the 
vaccine scheduled for that day and time with the help of his/her SNS user number.
* **SNS Users:** wants to take the vaccine on the scheduled day and time.
* **Nurse:** wants there to be SNS users on the queue list to take the vaccine.
* **Center coordinator:** performance of vaccination process (waiting times and affluence of SNS users).

#### Preconditions
* Be identified and authenticated;
* SNS user should have a valid vaccination scheduled.

#### Success Guarantee (or Postconditions)
SNS User is informed if he/she can go to the waiting room or if there is a mistake with the day and time appointment.
