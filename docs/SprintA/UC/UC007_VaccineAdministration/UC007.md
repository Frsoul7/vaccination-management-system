# UC007 - Vaccine Administration

## 1. Engineering Requirements

### Brief Format
A nurse uses the application to check the list of SNS users in waiting room. 
The nurse calls a SNS user who is first in the queue (FIFO). 
Then, the nurse verifies the SNS user info on the application: 1- health conditions;
2- scheduled vaccine type; 3- vaccination history.
Upon verification, the nurse receives instructions from system regarding the vaccine to be administered. 
After the administration process, the nurse registers the event in the system,
more precisely, registers the vaccine type, vaccine name/brand, and the lot number used. The system checks if all data are inserted and validates it.
Afterwards, the nurse sends the SNS user to a recovery room,to stay there for a given recovery period.

### Complete format

#### Main Actors 
Nurse

#### Stakeholders and Interests
* **Nurse:** verifies health conditions of SNS user and his/her info. Consult the vaccine administration instruction. Administers the vaccine and registers the event (type of vaccine, name/brand, lot number).  
* **SNS Users:** wants to take the scheduled vaccine to get immunity.
* **Center coordinator:** performance of vaccination process (managing centers capacity and slots availability). 
* **Administrators:** vaccine administration instructions registered in the system, type of vaccine and vaccines brands.
* **DGS:** immunization of population.


#### Preconditions
* Be identified and authenticated;
* List of SNS users in the waiting room;
* Type of vaccine and vaccines should be registered in the system;
* Defined administration methodology;
* SNS users' heath history;


#### Success Guarantee (or Postconditions)
* The nurse administrates the scheduled vaccine to SNS user punctually, who is then sent to recovery room.
* The SNS user stays in the recovery room for a given recovery period.

### Main Success Scenario (or Basic Flow)
1. A nurse checks the list of SNS users in waiting room.
2. The system shows the requested information.
3. The nurse calls a SNS user who is first in the queue.
4. The nurse request the SNS user info on the application.
5. The system returns the requested information.
6. The nurse verifies the SNS user health conditions, scheduled vaccine type and vaccination history.
7. Upon positive verification, the nurse requests the administration instructions for the vaccination process.
8. The system returns the instructions for the vaccination process.
9. The nurse administrates the vaccine to the SNS user.
10. The nurse registers the event in the system (vaccine type, vaccine name/brand, and the lot number used).
11. The system checks if all data are inserted, validates it and informes the success of operation.
12. The nurse sends the SNS user to a recovery room,to stay there for a given recovery period.

#### Extensions (or Alternative Flows)
[1-8]a. The nurse cancels the vaccine administration process.-
>The use case ends.

3a. The nurse may not respect the FIFO queue.
>The nurse calls a SNS user that meets the special conditions.(step 4)

7a. The Nurse founds an issue on the SNS User health condition history that invalidates the vaccine administration. 
>Use case ends.

#### Special Requirements
Only the nurses are allowed to access all user’s health data.
