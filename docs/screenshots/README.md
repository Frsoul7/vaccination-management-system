# Application Screenshots

This directory contains screenshots demonstrating the COVID Vaccination Management System.

## Structure

- **console/** - Screenshots of the console/terminal interface
  - Administrator features (employee management, vaccination centers, vaccines, etc.)
  - Receptionist features (SNS user registration, scheduling)
  - Center Coordinator features (center management, performance analysis)
  
- **gui/** - Screenshots of the graphical user interface
  - Nurse interface (waiting room, vaccine administration)
  - SNS User interface (scheduling, vaccination certificate)
  - Login screens and dashboards

## Naming Convention

Use descriptive names for screenshots:
- `console-admin-employee-list.png`
- `console-receptionist-schedule-vaccine.png`
- `gui-nurse-waiting-room.png`
- `gui-nurse-administer-vaccine.png`
- `gui-user-vaccination-certificate.png`

## Usage

These screenshots are used for:
- Project documentation
- Demo presentations
- User guide illustrations
- README.md examples
